# Week 1 – Project Selection

Two projects from the Project Bank (the minimum), plus one optional proposal.

| # | Project | Level | Why chosen |
|---|---|---|---|
| 1 | Network Port Scanner | Beginner | Builds the networking base (TCP/UDP, handshakes, banners) later projects rely on |
| 2 | Password Strength Analyzer | Beginner | Applies regex, information theory and attacker modelling; useful to end users |
| 3 (optional) | Encryption Tool (AES/RSA) | Intermediate | Natural follow-on: protects the data these tools help secure; proposal in Week 5 |

| Week | Focus |
|---|---|
| 1 | Fundamentals, lab, selection |
| 2–3 | Project 1: build, test, validate, report |
| 4–5 | Project 2: v1, improved model, tests, report; Project 3 proposal |
| 6 | Portfolio, final report, submission |

**Success criteria:** working CLI per tool, passing unit tests, documented limitations, built-in ethical-use controls, professional reports.
